# V2.2.1

发布日期：2026-06-18

## Feature
1. 在线更新新增备用服务器通道，可在设置中选择更新源；当常规更新通道不稳定时，更新流程会尝试备用通道。
2. 设置页新增示波器绘制方式，可在 GPU 加速与 CPU 绘制之间切换，便于在不同显卡环境下选择更合适的波形显示方式。
3. 设置页新增调试日志目录和接收日志保存目录的“打开文件夹”入口，查看日志、定位文件更方便。
4. 扩展功能页新增加载状态提示，首次打开数据转换、波形显示等较重功能时会有更清晰的等待反馈。

## Optimization
1. 优化软件启动速度，波形等扩展功能改为按需加载，并对示波器图形环境进行预热，减少冷启动阶段的等待和卡顿。
2. 优化串口底层收发和连接分发，串口打开、发送、接收、关闭在后台处理，主界面响应更顺畅。
3. 优化串口数据分发机制，波形显示、协议解析和自动化流程只在启用时订阅串口数据，降低不必要的处理开销。
4. 优化串口与烧录功能的协作，烧录功能临时使用串口后，FST 会尝试恢复原串口连接。
5. 优化网络调试的 UDP、TCP Client、TCP Server 收发流程，网络 I/O 在后台处理，大量收发时界面更不容易被阻塞。
6. TCP Client 目标地址新增 `127.0.0.1`、`localhost` 常用预设，并优化本地绑定等网络调试控件在窄窗口下的显示。
7. 优化蓝牙调试后台代理进程管理，SPP / BLE 启动、发送和停止状态反馈更稳定。
8. 优化波形显示绘制性能，支持大数据点抽稀绘制，GPU 渲染失败时会自动回退到 CPU 绘制。
9. 波形显示默认横轴调整为点数模式，连续采样数据查看更直观；已有时间模式配置仍会兼容保留。
10. 优化波形数据解析队列，连续大量数据进入时会合并处理，减少曲线刷新抖动。
11. 优化在线更新窗口的样式和状态展示，下载阶段文案更简洁，当前版本、最新版本和更新源信息显示更紧凑。
12. 优化数据转换页面布局，输入区和输出区调整为上下排列，小窗口下可读性更好。
13. 默认隐藏网络、BLE、SPP 的接收来源前缀，接收区日志更清爽；如需区分来源，仍可在设置中开启。
14. 补齐新增设置项、在线更新和波形显示相关的中英文翻译，提升界面文案一致性。

## Fix
1. 修复部分 Windows 系统缺少命令导致启动闪退的问题。
2. 修复硬件信息缺失时授权校验可能误判机器不匹配的问题，提高已激活设备的兼容性。
3. 修复客户端状态上报在网络异常时缺少超时保护，可能影响启动阶段稳定性的问题。
4. 修复接收区为空时执行打开、保存、复制等操作仍可能弹出阻断提示或继续执行的问题。
5. 修复部分接收数据分片为空或前缀信息不足时，接收区显示可能异常的问题。
6. 修复串口写入失败和连接异常时，提示信息不够准确的问题。
7. 修复波形单条解析设置切换后，校验状态和保存按钮状态未及时刷新的问题。
8. 修复波形逗号分隔数据不完整或数量不匹配时，可能被错误解析的问题。
9. 修复示波器在部分图形环境初始化失败时可能影响波形显示的问题，现会自动回退到 CPU 绘制。
10. 修复设置项变更后需要重启时，部分场景下重启应用路径不可靠的问题。
