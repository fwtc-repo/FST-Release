# V2.0.3

发布日期：2026-05-18

## Feature
1. 新增备用 File Browser 发布通道，支持将在线更新文件、安装包和便携包发布到备用服务器。
2. 发布脚本支持 Gitee、GitHub 和备用服务器多目标发布，并可按目标单独发布或并行发布。
3. 官网下载页支持动态读取发布元数据，自动更新最新版本号、包名、文件大小、发布日期和下载地址。

## Optimization
1. 优化在线更新通道测速逻辑，改为读取版本元数据并按响应时间和下载速度综合选择更新通道。
2. 优化在线更新备用通道选择流程，当 Gitee 和 GitHub 都不可用时再检查备用服务器，减少额外网络探测和误判。
3. 优化更新元数据解析，兼容简化版和完整版版本信息字段，并统一平台与版本校验逻辑。
4. 优化在线更新窗口复用逻辑，自动检查时避免重复创建窗口，手动打开更新窗口时会置顶并激活。
5. 优化发布流程，版本 JSON 不再内嵌完整更新说明，更新说明统一通过 release_notes manifest 和 Markdown 获取，减小版本元数据体积。
6. 优化官网首页视觉与文案，突出嵌入式调试工作台、日志检索、命令发送、趋势观察和固件烧录等核心能力。
7. 优化官网发布文档，补充备用服务器发布、并行发布、上传重试、校验重试和元数据顺序上传说明。

## Fix
1. 修复浅色文字 Logo 的资源打包引用，避免发布构建时因资源路径缺失导致编译失败。
2. 修复官网多页面开发提示区域和移动端首屏展示细节，减少布局冗余和显示异常。
