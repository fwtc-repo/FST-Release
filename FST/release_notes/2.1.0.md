# V2.1.0

发布日期：2026-05-22

## Feature
1. 新增网络调试能力，支持在同一软件内进行网络连接与调试操作，扩展了串口之外的调试场景。
2. 新增蓝牙调试能力，提供较完整的 BLE 调试流程，支持蓝牙连接与数据调试。
3. 新增可编辑键值下拉框组件，支持在配置项中进行更灵活的选择与编辑。
4. 新增发送内容与关键词策略的统一管控方案，便于集中管理多条发送与关键词相关配置。
5. 新增部分条目数量限制，防止配置无限增长导致界面与性能负担。

## Optimization
1. 优化网络连接状态栏样式与相关界面表现，连接状态展示更清晰。
2. 优化 BLE 连接相关交互与界面细节，连接过程反馈更直观。
3. 优化“关于”与“更新”入口结构，将两者合并，减少入口分散带来的操作成本。
4. 优化关键词与多条发送能力的协同方式，降低功能间配置差异。
5. 优化下拉框相关交互体验，提升复杂配置场景下的可用性。

## Fix
1. 修复网络调试接入后的部分样式异常问题，提升界面一致性。
2. 修复下拉框（ComboBox）在特定场景下的 UI 显示问题。
3. 修复并完善网页与客户端联动中的若干细节问题，减少使用过程中的异常体验。
