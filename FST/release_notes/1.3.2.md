# V1.3.2

发布日期：2026-01-22

## Feature
1. 新增设置页面框架，支持编码格式设置。
2. 新增恒玄芯片基础烧录功能。
3. 更新内容展示支持 Markdown 格式。
4. 引入 OpenSSL 相关准备工作，为软件授权框架打基础。
5. 启动服务器官网相关开发。

## Optimization
1. 优化 UI 布局、扩展组件显示方式和配置存储逻辑。
2. 更新服务器域名和发布脚本，支持 Markdown 发布说明。

## Fix
1. 修复最大化后主页面顶部出现空隙的问题。
2. 修复关键词筛选页面和无串口场景下的异常问题。
3. 修复串口波特率、关键词等配置不保存的问题。
4. 修复关键词刚启动时不会筛选的问题。
5. 修复扩展组件初始显示异常的问题。
6. 修复 BES 烧录完成后工厂区按钮状态始终恢复的问题。
