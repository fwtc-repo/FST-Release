# V1.8.3

发布日期：2026-04-30

## Feature
1. 新增数据转换功能。
2. 接收区、发送区和关键词筛选支持展开和收起。
3. 串口连接设置支持折叠不常用功能。
4. 支持滚轮修改文字大小。
5. 数据转换支持暗黑模式。

## Optimization
1. 更新协议解析功能。
2. 重新设计主页 UI，优化主页边框、提示弹窗颜色和连接设置记忆。
3. 重构关键词筛选颜色选择方案。
4. 统一字体大小和样式。

## Fix
1. 修复主页接收/发送区域位置不保存的问题。
2. 修复 QComboBox 下拉三角形不显示的问题。
3. 修复倒三角间隙、文字大小和暗黑模式展开按钮颜色问题。
