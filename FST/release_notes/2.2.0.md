# V2.2.0

发布日期：2026-06-12

> **升级提示：** 本版本重点提升数据转换、协议解析、主界面布局和大日志使用体验。
> 如果你经常需要查看日志、解析协议、筛选数据或做格式转换，建议升级到本版本。

## Feature
1. 新增选中文本右键数据转换入口，可在日志、发送内容、输入框等文本区域中直接进行常用转换、校验和计算。
2. 新增主界面右上角页面视图设置按钮，可快速显示或隐藏左侧连接区、中间收发区、右侧工具区，并自动记住视图布局。
3. 接收区搜索新增正则表达式模式，并补充上一条、下一条搜索导航。
4. 设置页中条目较多的下拉框新增搜索能力，查找串口参数、字体等配置项更方便。
5. 右下角新增当前文本编码显示与快捷切换入口，便于确认接收、发送和数据转换时使用的编码。

## Optimization
1. 优化数据转换工具界面、文案和样式，HEX、文本、Base64、URL、Unicode、JSON、进制、大小端、浮点数、ASCII 与时间相关转换展示更清晰。
2. 优化协议解析和测试协议解析流程，完善解析结果层级展示，字段关系、长度字段和解析状态更易读。
3. 优化 Modbus RTU、Modbus TCP、CAN、CANopen 等协议解析预设，长度字段和可变长度数据的默认配置更准确。
4. 优化恢复出厂设置和首次使用时的默认布局比例，主界面、收发区、关键词筛选区的空间分配更合理。
5. 优化扩展页标签和工具页面的横向尺寸控制，窄窗口下标签可省略或滚动，工具区不易被撑宽。
6. 优化接收区文件保存相关体验，保存配置与主设置页面保持一致，减少重复配置。
7. 优化自动化流程界面与扩展能力，并改进更新说明中的 Markdown 颜色样式展示。
8. 接收和发送菜单中的设置项已在总设置页面补齐对应映射，集中管理更完整。
9. 设置页面的字体选择会直接展示字体本身的样式，选择效果更直观。
10. 设置页面关闭时如果有未保存修改会进行提示，降低误关导致配置丢失的风险。
11. 补齐数据转换等新增界面的多语言翻译，提升中英文界面一致性。

## Fix
1. 修复大量接收内容没有回车换行时，页面可能卡顿的问题。
2. 修复定时发送、超时分割未勾选时，相关数字参数无法编辑的问题。
3. 修复设置编码格式后下次启动不生效的问题。
4. 修复多条发送恢复过程中的潜在异常。
5. 修复多条发送和关键词筛选中菜单删除失效的问题。
6. 修复部分协议解析预设中长度字段类型和校验范围不完整的问题。
7. 修复 Toast 提示样式在部分场景下显示异常的问题。
8. 修复深色主题下波形标记删除按钮图标显示不一致的问题。
