# V1.8.0

发布日期：2026-04-27

## Feature
1. 新增强制更新能力。
2. 关键词搜索支持使用 `//` 注释单行。
3. 支持多语言设置、更多中文内容和更多翻译项。
4. 新增授权激活模式，并集中管理加密配置文件。
5. 关键词筛选支持多种颜色，并对关键词颜色能力接入证书限制。
6. 新增亮色模式、定时发送、示波器配置存储、示波器导出和波形显示框架。
7. 示波器支持图例/曲线联动、OpenGL 加速、多线程优化、放大缩小、复位和数据导出。
8. 支持自定义全局字体大小，并区分 UI 字体大小和接收框字体大小。
9. 新增意见反馈页面。
10. 重新调整目录架构。

## Optimization
1. 优化服务器代码、激活页面和密码混淆。
2. 优化 BES 烧录稳定性。
3. 优化在线升级后重启和配置保留流程。
4. 优化示波器刷新、检索多条目完整协议字符算法和协议设置区域显示。
5. 优化配置存储逻辑，增加关闭前备份，降低配置丢失风险。

## Fix
1. 修复 BES 烧录若干问题。
2. 修复更新中重复点击下载、潜在空指针、单例退出死机等问题。
3. 修复设置页面、关键词列表、发送框字体、文字大小、左上角菜单栏、示波器隐藏按钮等显示问题。
4. 修复英文模式下更新页面闪退。
5. 修复升级后不重启、升级后配置文件丢失等问题。
6. 修复关闭时可能丢失所有配置数据的问题。
