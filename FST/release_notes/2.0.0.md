# V2.0.0

发布日期：2026-05-13

## Feature
1. 新增 STC、STM32、GD32、ESP32 固件烧录支持，完善烧录入口、参数配置和日志提示。
2. 新增恢复出厂设置功能，支持快速恢复默认配置。
3. 升级在线更新流程，优化更新通道选择、更新说明展示、差异下载和更新包校验。
4. 完善示波器功能，优化标记、缩放和数据查看体验。

## Optimization
1. 优化主界面、标签页、分割线、页面边框和小窗口布局，提升不同窗口尺寸下的显示一致性。
2. 优化接收区配色、扩展功能按钮和关键词筛选区域的交互与显示效果。
3. 更新中英文翻译和第三方开源组件说明。

## Fix
1. 修复示波器标记显示异常的问题。
2. 修复关键词筛选区域分割条宽度异常的问题。
3. 修复标签页最小宽度、小对话框布局和部分在线更新流程中的已知问题。
