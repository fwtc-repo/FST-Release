# V2.0.2

发布日期：2026-05-15

## Feature
1. 新增 FST 官方网站内容，包括首页、下载页、使用教程、更新记录页和授权预览页。
2. 新增历史更新记录体系，发布包会携带版本 Markdown 与 manifest，在线更新和官网可按版本读取更新说明。
3. 在线更新支持在跨版本升级时汇总展示多个版本的更新记录。
4. 接收区查找新增高亮颜色选择，并记住大小写、全词匹配、循环查找和颜色偏好。

## Optimization
1. 优化关键词高亮、示波器曲线和协议解析片段的颜色选择方式，统一为带色块、名称和自定义颜色入口的菜单。
2. 优化接收区查找性能，改为后台分批检索，减少大文本查找时的界面卡顿。
3. 优化协议解析界面，将新增片段入口合并为 Add Segment 菜单，并改善片段颜色列与滚动条显示。
4. 优化发送区和关键词列表展开按钮样式，到达底部时自动隐藏，悬浮显示更贴合接收文本区域。
5. 优化关键词筛选结果的末尾空行处理，减少筛选展示中的多余空白。
6. 优化授权状态加载流程，增加授权可用性日志，并在设备信息校验前更快识别本地高级授权。
7. 优化官网发布脚本和 Gitee 发布流程，支持发布版本更新记录并校验对应 raw 文件。
8. 更新中英文翻译，补齐新增颜色、更新记录、下载通道和在线更新相关文案。

## Fix
1. 进一步加固在线更新对 0 字节文件和文件写入失败的处理，避免下载或创建空文件时流程异常。
2. 修复协议解析界面部分控件布局、颜色选择和默认片段配置的显示问题。
