# V1.9.1

发布日期：2026-05-08

## Feature
1. 新增查找功能。
2. 实现自定义标题栏。
3. 支持点击串口等连接栏区域展开和收起。
4. 新增恢复出厂设置功能。
5. 支持关键词和多条发送列表的导入、导出。
6. 关于页面新增更多条目。

## Optimization
1. 优化启动速度、颜色在不同主题下的显示、底部状态展示和 Tab 关闭按钮样式。
2. 优化主页左侧菜单栏、连接栏、Logo、页面边框距离和主页整体 UI。
3. 优化设置页面、暗黑模式、工具按钮、扩展按钮、复选框、下拉框和工具按钮样式。
4. 优化存储配置和升级打包流程。

## Fix
1. 修复菜单栏消失、浏览文件、主页不保存和布局错乱问题。
2. 修复没有勾选扩展功能时的布局异常。
3. 修复进度条中心文字颜色错误。
4. 修复设置页面样式问题。
5. 修复恢复出厂设置后 VIP 状态错乱。
6. 修复展开按钮背景颜色不一致的问题。
